# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 이 폴더의 성격

코드 저장소가 아니라 **엑셀 자료로 보고서를 만드는 작업 폴더**입니다. 빌드·린트·테스트 명령은 없습니다.

- `연습폴더/` — 원본 자료 (읽기 전용으로 취급, 수정하지 않음)
  - `1_매출_이번주.xlsx` — 날짜 | 상품 | 수량 | 단가 | 매출 (15행: 10/5~10/9 × 커피 원두·드립백·머그컵)
  - `2_고객문의.xlsx` — 날짜 | 유형 | 접수 | 처리 완료 (20행: 5일 × 배송 문의·교환·반품·상품 문의·결제 오류)
  - `3_업무진행.xlsx` — 업무 | 담당 | 상태(완료/진행 중/대기) | 마감 (5행)
- 폴더 최상단 — 만들어진 보고서
  - `주간보고서_1005-1009.xlsx` — 세 자료 통합. 첫 시트 `주간보고서`가 표를 만들고, 나머지 시트(`매출`·`고객문의`·`업무진행`)는 원본을 복사해 둔 것
  - `매출요약_1005-1009.xlsx` — 매출 자료만 사용. 시트 한 장(`매출요약`)에 핵심 3줄 → 상품별·일별 표 → 원본 데이터와 검산 열 순서로 배치

원본의 날짜(`10/5(월)`)와 마감(`10/7`)은 날짜 형식이 아니라 **텍스트**입니다. SUMIFS 조건으로 쓸 때는 이 텍스트와 똑같이 맞춰야 합니다.

## 작업 환경 (Windows, 중요)

- **Python이 설치되어 있지 않습니다.** `python`을 실행하면 Windows Store 스텁이 뜨면서 실패하고(exit 49), `markitdown`도 없습니다.
- **Excel 16이 설치되어 있습니다.** 엑셀 파일을 읽고 쓸 때는 PowerShell에서 `New-Object -ComObject Excel.Application`을 사용합니다. 작업이 끝나면 `finally`에서 `$x.Quit()`를 호출합니다.
- 한글이 들어간 `.ps1` 파일은 BOM이 없으면 PowerShell 5.1에서 글자가 깨집니다. 이렇게 실행합니다:
  `Invoke-Expression (Get-Content -Raw -Encoding UTF8 <script.ps1>)`
- COM 사용 시 주의할 점
  - `Range.Value2`에 배열이나 셀 값을 바로 넣으면 `InvalidCastException`이 납니다. 원본 범위는 `Range.Copy(대상Range)`로 복사합니다.
  - 새 통합문서를 만들기 전에 `SheetsInNewWorkbook = 1`로 바꾸고, 작업 후에는 원래 값으로 돌려놓습니다.
  - 저장은 `SaveAs(path, 51)`(xlsx)로 합니다. 레이아웃은 `ExportAsFixedFormat(0, pdf)`로 PDF를 만들어 확인합니다.

## 보고서 작성 방식 (사용자 요청에서 확인된 것)

- **표는 맨 위에**, 설명 문장은 표 아래에 둡니다. 다만 "표 위에 핵심 N줄"처럼 따로 요청하면 그 요청을 따릅니다.
- **지정한 자료만 사용합니다.** 자료에 없는 비교(전주 대비, 목표 대비 등)는 넣지 않습니다.
- 숫자를 꼼꼼히 보는 팀장님이 읽는 보고서입니다.
  - 표의 모든 값은 원본 셀을 참조하는 **수식**으로 넣습니다(SUMIFS, INDEX/MATCH 등).
  - 핵심 요약 문장도 가능하면 `TEXT()`를 쓴 수식으로 만들어, 원본이 바뀌면 함께 바뀌게 합니다.
  - 검산 열(예: 수량×단가)과 비중 합계 100%를 함께 보여 줍니다.
- 서식: 글꼴 `맑은 고딕`, 천 단위 쉼표, 비율은 `0.0%`. 표 머리글은 남색 배경에 흰 글씨, 합계 행은 굵게. A4 한 장에 인쇄되도록 맞춥니다.
- 결과 파일 이름은 `<보고서종류>_<MMDD-MMDD>.xlsx` 형식으로 합니다.
